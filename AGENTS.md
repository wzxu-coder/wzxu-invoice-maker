# WZXU Invoice Maker

Use npm. Commands: `npm run dev`, `npm run lint`, `npm run typecheck`, `npm run test`, `npm run test:e2e`, `npm run build`.

Keep invoice data local-first in IndexedDB. Do not add authentication, cloud storage, logs, URLs, or network payloads containing invoice content without an explicit product decision. Keep all financial totals in the pure calculation engine and run tests after changing calculations, storage, PDF output, or forms. Always spell the brand `WZXU`.
